# Plataforma v0.4.0: diseñador de flujos de insights

## Resumen

FE004 añade la sección **Flujos de insights**:

- listado de flujos con autor, última modificación, última ejecución y estado; crear, duplicar, renombrar y borrar;
- editor visual con React Flow: paleta de nodos Sampling, Prompt y Output (arrastrar o pulsar), conexiones con el ratón o desde el panel, reglas de conexión con el motivo de cada rechazo, zoom y desplazamiento;
- paneles de configuración: filtros de FE002 con estimación de conversaciones, métodos de muestreo, plantilla con variables, modelo, temperatura, formatos de salida y tipos de output;
- validar, guardar como JSON (idéntico al recargar) y ejecutar;
- ejecución simulada en segundo plano con el progreso de cada nodo por polling, resultados por output (tabla navegable, métrica con gráfico y tabla, informe) e historial.

El prompt no llama a ningún LLM: da resultados deterministas y coherentes con el análisis de cada conversación, detrás de la interfaz `PromptRunner` ([ADR-006](../decisiones/adr-006-ejecucion-de-prompts-simulada.md)).

## Evidencia

- `./scripts/ci.sh` termina con código 0: 508 tests de backend, 230 de front, lint, build y auditorías sin vulnerabilidades.
- Fuzzing de 9.000 peticiones sin `5xx` (tras corregir el único fallo encontrado).
- Tests de flujos en verde con 4 combinaciones de semilla y fecha de referencia.
- Chrome contra la API real: recorrido completo del criterio 21 sin errores de consola.

## Limitaciones conocidas

- Resultados simulados: no demuestran la calidad de un LLM.
- Flujos y ejecuciones en memoria (se pierden al reiniciar); se conservan las 50 ejecuciones más recientes por flujo.
- Sin edición colaborativa: gana el último guardado.
- Con los roles por defecto no hay un rol de solo lectura de flujos; FE006 permitirá crearlo.

## Rollout

Etiqueta local `v0.4.0` sobre `main`, sin despliegue. Dependencia nueva en el front: `@xyflow/react` (MIT), en rutas diferidas. El backend no añade dependencias.
