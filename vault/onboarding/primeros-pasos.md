# Primeros pasos

## Para personas

1. Lee el [README del proyecto](../../README.md) para arrancar la API y la web, y las [instrucciones del proyecto](../../AGENTS.md). Para conectar un LLM (Gemini, OpenAI o Anthropic), sigue el [runbook del servicio de LLM](../operaciones/runbook-servicio-llm.md).
2. Recorre el [índice del vault](../Home.md).
3. Consulta el [gobierno](../Governance.md) antes de crear conocimiento.
4. Familiarízate con la [arquitectura de la plataforma](../arquitectura/arquitectura-de-la-plataforma.md), la [del harness](../arquitectura/arquitectura-del-harness.md), la [decisión inicial](../decisiones/adr-001-markdown-y-obsidian.md) y el [glosario](../glosario/terminos-del-harness.md).
5. Usa `/spec → /plan → /build → /test → /review → /ship` para ejecutar un cambio; su documentación vive en `features/FEXXX-descripcion-breve/`.

## Para agentes

1. Consulta `vault/Home.md` antes de asumir contexto relevante.
2. Busca una entrada existente antes de crear otra.
3. Contrasta la [arquitectura](../arquitectura/arquitectura-del-harness.md), las [decisiones](../decisiones/Index.md) y el [glosario](../glosario/terminos-del-harness.md) cuando sean relevantes.
4. Distingue hechos, decisiones e hipótesis y cita el archivo utilizado.
5. No reproduzcas valores sensibles y respeta los gates del ciclo.
