# Features

Cada feature tiene su propia carpeta `FEXXX-descripcion-breve/`:

- `XXX`: número incremental de tres dígitos (el mayor existente + 1; la primera es `FE001`).
- `descripcion-breve`: 4 o 5 palabras en `kebab-case`, minúsculas, sin tildes.
- Contenido: `spec.md`, `plan.md`, `VERIFY.md`, `REVIEW.md` y `SHIP.md`, generados por los skills del ciclo.

Ejemplo: `FE001-transcripcion-de-llamadas-genesys/spec.md`.
